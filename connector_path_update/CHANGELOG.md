# 更新记录

## 2026-11-17
- 新增 segment 级连接器到连接器最长简单路径搜索。
- 支持跨多个 branch 的多段连续路径，不把 branch 错误简化为单根管段。
- 增加环路、经过中间连接器、自环排除、无连接器对等单元测试。
- 原始实现样例记录：110 节点/116 segment，CON01→CON08，约 2341.4 mm；该数据不是优化版的重新实测结果。

## 2026-11-17 优化
- 无环连通分量改用加权树终端直径双遍历，避免枚举路径。
- 含环/平行边分量改为每个连接器起点只做一次精确 DFS，同时比较所有后续连接器，避免旧版按连接器对重复搜索。
- 加入连通分量隔离、剩余边权重上界剪枝、确定性等长路径择优。
- 对重复节点编号、未知节点引用、缺失/负数/NaN/无穷长度改为明确报错，避免静默丢失拓扑。
- 扩展回归测试：不连通分量、非法长度、未知节点引用。
- v4 二维布局器尚未接入本模块；不将算法分析结果冒充为已完成布局改造。
