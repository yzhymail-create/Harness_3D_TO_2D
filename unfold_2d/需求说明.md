## 一、目标与交付物

把 3D 拓扑展开成 2D DXF 工程图。DXF 是真正的二维工程图，带尺寸与图层，可直接用于工程制图与生产；不是只看不能改的预览图。

三者区分（2026-11-16 通话中确认）：

- 3D JS 查看器：Three.js 在浏览器里看立体结构，能点节点、拖动旋转。
- 网站平面预览：给人看的平面图，不能编辑。
- DXF 展开图：本需求的交付物，CAD 能打开、能编辑、能出图。

输出：

- DXF 文件（CAD 可直接打开）
- 2D 数据表（Excel）：每根管子的 2D 起终点坐标、长度、直径；每个节点的 2D 坐标、类型

## 二、基本原则（v2 延续）

1. **长度真实**：每根管子在 2D 上画成直线，长度 = 3D 真实弧长（1:1）。
2. **拓扑不变**：谁连谁，跟 3D 一致。
3. **不重叠**：管子之间不许压着画。共线重合才算"压着画"；横向 X 形交叉允许。
4. **不分页**：一个层级一张图，不许拆成多页。
5. **确定性**：同样输入 → 同样输出。

## 三、块（BLOCK）（2026-11-16 确认）

- 每一个管子、每一个卡扣、每一个连接器，在 DXF 里都转成一个块（BLOCK/INSERT）。
- 块可单独选中、移动；块名与 3D 里的名字、编号对应。
- 注：v2 写的是管子 LWPOLYLINE、连接器/卡扣 CIRCLE+TEXT；本条取代 v2 的图形表示。块内几何画什么，见第十一节未决问题 2。

## 四、工作流程：先投影，再分区域调整（2026-11-16 定）

不是一次性把整张图全摊平。分两步走：

1. **先投影**：不管 3D 里多交错，先把 3D 投影到 2D 平面，得到初始布局。
2. **再分区域调整**：分区域、逐段调整线段位置，直到图面清晰。

展开前先从视觉上判断 3D 大概是什么结构（有没有环、主干什么走向），再按结构展开。程序没有视觉判断，所以流程是：先出带结构的预览图，用户看过、指出哪里挤、哪里该往下放，再调，再出正式 DXF。

## 五、主干：最长怎么算（2026-11-16 定）

- "最长" = 每根管子在 3D 里中心线的真实弧长（从一个端点到另一个端点，沿中心线量的长度）。
- 不是体积，不是投影后的长度，是原始模型里那根管子本身最长。
- 最长的一根为主干，水平画在中间。

## 六、环形结构（2026-11-16 定，分两种情况）

必须先判断有环还是无环，走不同的分支（if/else），逻辑要分清：

- **有环**（如井字形）：先把环完整画出来，保持它本来的形状。不许在环上剪个口拉直（剪口是错的，环就不是环了）。再从环的每个角出发，找最长的段作主干。
- **无环**：直接取整根最长的管子作主干。

## 七、绘制顺序：长度数组逐个剥离（2026-11-16 定）

1. 把所有管子的长度放进一个数组。
2. 找出最长的，画成主干，从数组中去掉。
3. 剩下的再找次长的，当下一根主干画到图上，去掉。
4. 如此重复，直到数组为空。

主干先画，再画次长，依次有主有次。

## 八、分支画法（2026-11-16 定，含 v2 延续）

- **次长分支（单根）**：垂直于主干画。
- **同一分支点再来一根**：第一根保持 90° 垂直，新增的一根与它夹 30°（即一边 90°、另一边 60°），往同一侧偏，不重叠。
  - 注：讨论中用户先提中间夹 45°，后暂定 30°；下次使用时由用户最终确认（见第十一节问题 1）。
- **多分支（v2）**：以垂直向上为基准，30° 间隔对称散开（2 根：75°/105°；3 根：60°/90°/120°；4 根：45°/75°/105°/135°）。默认画上方，上方相交改下方，上下都相交记 ERROR，不强行压着画。
- **先找齐分支点再画（v2）**：找出主干上所有分支点，按从左到右排序，找齐排好再逐个画，不边找边画。
- **节点坐标（v2）**：端点节点（连接器/分叉/接头）= 所接管子端点的 2D 坐标；卡扣按 3D 时在管子上的弧长比例 t，放在 2D 直线段对应比例位置。
- **标注（v2）**：管子中点旁 `Seg01 Φ12 L=345.6`；连接器旁 `CON01`；卡扣旁 `CL01`；暂不画图框标题栏，只绘制几何与标注。

## 九、干涉处理：中途拐弯（2026-11-16 定）

- 画分支时逐段检查是否与已画分支干涉，要能发现干涉才画。
- 多段分支（比如 6 段）：第 1、2 段不干涉，第 3 段起干涉时，不重画整根、不整体改角度；在第 2 段结束的那个点拐一下，避开后再继续往后画。
- 拐多少：拐到刚好避开旁边分支为止，一般十几度，以不干涉为度，不做大角度拐弯。
