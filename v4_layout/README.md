# v4-layout-engine（实验分支）

本分支从 master 创建，不修改 master。用于承载线束 3D→2D 展开算法的 v4 重构。

## 当前提交范围

- 新增独立二维布局引擎原型，输入沿用 topology.json 的 nodes / segments / branches。
- 将源拓扑、真实长度与二维布局坐标分开保存。
- 输出每个节点、分支、线段的二维坐标及长度校验数据。
- 对连通分量分别处理，输出未放置项、长度误差、干涉和警告。

## 当前边界

这是算法原型，不是已经验收的完整 v4 软件。尚未接入 v3 的 DXF BLOCK/INSERT、Excel 和 HTML 查看器；复杂真环布局仍待实现；连接器和卡扣的显示几何尚未生成；尚未通过 IP-Harness 110 分支回归测试。不能把本提交视为生产版。

任何无法满足端点距离与真实长度约束的分支都会在报告中标记，不应静默丢弃或伪造长度。

## 运行

需要 Python 3.8+，无第三方依赖：

```bash
python v4_layout/layout_engine.py topology.json -o layout_v4.json --clearance 5
```

## 设计原则

- 不改写源拓扑。
- 真实 3D 长度不因布局优化而变化。
- 二维布局只改变坐标和折线路径。
- 同样输入与参数应产生确定性输出。
- 先生成初始布局和质量报告，再逐步实现局部避让与环布局。
